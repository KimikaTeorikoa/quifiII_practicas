# Galdetegia

## Eredu sinpleak Python erabiliz
* Lehenengo ereduan, kaxa bateko partikulari dagokionean, zer gertatzen zaie energia-mailei potentzialaren zabalera handitzean? Erabili Python energia $n$ zenbaki kuantikoaren funtzioan irudikatzeko.
* Kalkulatu oinarrizko egoeraren energia eskuz eta zenbatetsi zenbakizko hurbilketaren errorea $\Delta x$-ren balioaren arabera.
* Putzu finituaren kasuan, aldatu potentzialaren sakonera eta ikusi nola aldatzen diren soluzioak. Azaldu emaitzak.
* Osziladore harmonikoan, nola daude bananduta energia-mailak? Egin energiaren adierazpen grafikoa $v$-ren funtzioan. Irudikatu dentsitatea zenbaki kuantikoaren balioa handitu ahala.
* Lotura kimikoaren gure gutxieneko ereduan, bi potentzial-putzuen arteko distantzia definitu dugu. Aldatu distantzia hori eta lortu orbital lotzaile eta antilotzailearen soluzioak. Irudikatu energia horiek putzuen arteko banaketaren funtzioan.
